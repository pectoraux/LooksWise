# LooksWise SDK Strategy

Target SDKs:

- Web / React
- iOS
- Android
- React Native
- Flutter
- Server-side JavaScript/TypeScript, Python and similar HTTP clients through generated API schemas

Core client primitives:

`LooksWiseCamera`
`LooksWiseLookPicker`
`LooksWiseLookView`
`LooksWiseEditor`
`LooksWiseTryOn`
`LooksWiseJobMonitor`

SDKs must share the same Look, Transformation, AppearanceState and API contracts. Platform-specific camera/AR primitives may be native.
