# LooksWise Architecture Lock

**Status:** FROZEN
**Architecture Version:** 1.0

1. Look is the primary consumer-facing abstraction.
2. Transformation Recipe is the canonical representation of a professional transformation.
3. AppearanceState is the canonical structured subject representation.
4. Providers/models are implementations of capabilities; domain code does not bind to vendors.
5. OpenRouter may be used as a provider/gateway implementation but is not a domain abstraction.
6. No Zeck-specific contract is part of v1.0. Future execution-engine integration requires an Architecture Change Request and new architecture version.
7. Social validation is first-class and separate from private simulation.
8. Author-controlled opinion audience policies are server-enforced. Gender restrictions are participation controls, subject to product/legal policy, not objective beauty scores.
9. External social sharing is explicitly distinguished from controlled in-product opinion.
10. Real-world outcomes are separate from simulations and feed the Reality Engine only within consent/governance scope.
11. Reality/fidelity scores must expose evidence tier and uncertainty.
12. Medical-aesthetic simulation is isolated from ordinary beauty/fashion transformations.
13. Live AR and high-fidelity media rendering are separate runtimes.
14. Transformations are non-destructive/versioned where practical.
15. Every generated artifact has provenance.
16. API/SDK contracts expose capabilities, not provider-specific implementation details.
17. Authority lives in backend domain modules; frontend and LLMs do not become authoritative.
18. Architecture versions are immutable once frozen.
19. Architecture changes require explicit Architecture Change Request and a new immutable version.
20. Verification evidence is required before architect approval.
21. One Work Item per implementation branch/PR.
22. Only the architect is authorized to approve/merge implementation PRs.
23. External distribution adapters are non-authoritative target integrations; canonical Look state remains owned by LooksWise.
24. Semantic region identifiers are stable within architecture v1.0.
