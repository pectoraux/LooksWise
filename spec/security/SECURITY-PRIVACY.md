# Security and Privacy

- Server-side authorization is authoritative.
- Appearance representations, measurements and medical-aesthetic records are sensitive data classes.
- Consent scopes are explicit, versioned and revocable where applicable.
- Signed/scoped media access is preferred over public object URLs.
- Social audience policies are evaluated server-side.
- Provider credentials stay behind provider adapters.
- Audit records capture privacy, moderation, medical and learning actions.
- Data used for Reality Engine learning must be traceable to an allowed consent scope.
