# Implementation Worker Runbook

1. Read `AGENTS.md`.
2. Read the active Work Item.
3. Read every referenced requirement and acceptance criterion.
4. Inspect current code and tests before changing anything.
5. Implement the minimum complete change.
6. Add evidence and verification.
7. Run local checks.
8. Open a PR whose body identifies the Work Item, requirements, change surfaces, verification, and evidence.
9. Stop after the Work Item is ready for review.

Workers do not self-approve, self-merge, or rewrite architecture authority.
